# Лабораторная работа №4: Взаимодействие процессов (потоков): взаимное исключение и синхронизация

## 1. Общие сведения
* **Дисциплина:** Операционные среды и системное программирование (ОСиСП).
* **Вариант:** №22 (Раздел В: Система массового обслуживания — «Синхронизация статистики»).
* **Студент:** ID = 095.
* **Используемые механизмы синхронизации:** `Critical Section` (CRITICAL_SECTION), `Semaphore` (HANDLE).

---

## 2. Краткое описание программы
Программа моделирует трехступенчатую систему массового обслуживания (СМО) конвейерного типа:
$$\text{Generator} \longrightarrow \text{Stage 1} \longrightarrow \text{Stage 2} \longrightarrow \text{Stage 3} \longrightarrow \text{Collector}$$

### Основные компоненты:
1. **Generator (1 поток):** Генерирует поток заявок с контролируемым темпом.
2. **Рабочие ступени (Stage 1..3):** Каждая ступень содержит пул из 2 или 4 параллельных потоков.
3. **Collector (1 поток):** Собирает обработанные заявки и фиксирует сквозное время их прохождения.
4. **Ограниченные очереди (ThreadSafeQueue):** Буферы емкостью 50 элементов, синхронизированные парой семафоров (`m_hItems`, `m_hSlots`) и `CRITICAL_SECTION` для исключения переполнения и гонок.
5. **Сбор статистики (StatisticsManager):** Реализует два исследуемых режима:
   * **Global CS:** единая критическая секция на всю статистику системы (высокий Lock Contention).
   * **Per-Stage CS:** изолированная критическая секция на каждую ступень (Fine-Grained Locking).

## 3. Требования к среде выполнения
* **ОС:** Windows 10 / 11 (x64).
* **Компилятор:** MSVC (Visual Studio 2019 / 2022) с поддержкой C++17 или новее.
* **Windows SDK:** Версия 10.0 или выше.
* **Инструменты анализа данных:** Python 3.8+ с библиотекой `matplotlib` (для генерации графиков).
